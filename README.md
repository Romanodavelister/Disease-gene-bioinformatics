# Locating the Variant in UCSC

**a. Where is the variant located relative to your gene?:** The variant is located within the F5 gene on chromosome 1 (1q24.2), at approximately chr1:169,549,811 on GRCh38/hg38.

**b. Is it in an exon, intron, UTR, splice region, or another region?:** It is located in coding exon 10 of the F5 gene.

**c. Is it likely in a coding or non-coding region based on the displayed annotations?:** It is in a coding region, because the variant changes the protein sequence from arginine (R) to glutamine (Q), producing the missense change p.Arg534Gln. ClinVar annotates it as a missense variant.

**d. Based on its location and ClinVar information, briefly explain how the variant might affect the gene or gene product.** Because the variant occurs in a coding exon, it changes the Factor V protein. ClinVar reports that p.Arg534Gln (Factor V Leiden) disrupts an activated protein C cleavage site, reducing normal APC-mediated inactivation of Factor V and producing activated protein C resistance.

**e. What additional evidence would be needed before concluding that the variant causes disease?:** Additional evidence could include functional laboratory studies, clinical observations in affected individuals, segregation studies in families, population-frequency data, and consistent results from multiple independent studies. These types of evidence help determine whether the variant's molecular effect is associated with the disease phenotype rather than simply occurring alongside it.

# Interpretation

The UCSC Genome Browser showed that the F5 gene is located on chromosome 1 and contains several exons and introns, with the NM_000130.5 transcript representing the reference sequence. The c.1601G>A (p.Arg534Gln) variant is located within a coding exon and changes arginine to glutamine, making it a missense mutation.
